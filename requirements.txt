# Minimum versions rather than exact pins, so the project installs on any
# Python from 3.10 through 3.14. Exact pins tie you to one interpreter: a
# wheel built for 3.12 simply does not exist for 3.14, and pip then falls back
# to compiling from source, which needs a C/Rust toolchain and usually fails.
#
# Verified green against fastapi 0.141, pydantic 2.13, pytest 9.1,
# pytest-asyncio 1.4, psycopg 3.3 and reportlab 4.0 — i.e. the versions pip resolves today.

pydantic>=2.10
